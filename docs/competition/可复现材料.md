# 监盘通可复现材料

## 仓库与产物

- 源码仓库：<https://github.com/tentyou/Tenken>
- 最新安装包：<https://github.com/tentyou/Tenken/releases/latest>
- 每次 `main` 构建通过后自动发布 APK 和 SHA-256 校验文件。

## 环境要求

- Windows、macOS 或 Linux
- JDK 21
- Android SDK 36.1
- Android 8.0（API 26）以上设备或模拟器

## 构建

```powershell
git clone https://github.com/tentyou/Tenken.git
cd Tenken
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

macOS/Linux 使用：

```bash
bash ./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 复现实验

1. 安装 APK，首次启动允许相机权限。
2. 打开“线上同步 → 连接设置”。
3. 输入纯 Token、`Bearer <Token>` 或完整 `valuation-mcp` JSON 配置。
4. 使用编号 `20250715002` 的测试项目验证项目列表与只读同步。
5. 在“盘点资产”选择“待盘点”，确认只显示未完成资产。
6. 切换到批量模式，选择至少两项，执行共用照片盘点。
7. 完成拍摄，确认所选资产分别显示照片数量和已生成 PDF。
8. 重新同步项目，确认本地盘点范围与现场证据仍然保留。
9. 导出项目 ZIP，核对盘点表和 PDF。

## 可选真实 MCP 自动测试

将竞赛专用 Token 仅放入当前进程环境变量，禁止写入仓库：

```powershell
$env:VALUATION_MCP_TEST_TOKEN = '<竞赛专用Token>'
.\gradlew.bat :app:testDebugUnitTest --tests '*McpLiveReadTest'
Remove-Item Env:VALUATION_MCP_TEST_TOKEN
```

该测试只读取测试项目，不写远端，也不会输出 Token。未提供环境变量时自动跳过。

## 验收结果

- 单元测试覆盖 MCP 握手、SSE、分页、只读工具白名单、Token 加密、完整快照、同步身份保留、数据库迁移和共享照片。
- GitHub Actions 在干净的 Ubuntu 环境执行测试与构建。
- Release 附带 SHA-256，可核对下载文件完整性。

## 数据与凭据说明

仓库不提供客户生产 Token、业务数据、照片或数据库。复现者需申请只读测试 Token；演示结束后应撤销。也可以不配置 MCP，使用内置示例或本地模板验证离线拍照、PDF 和 ZIP 流程。
