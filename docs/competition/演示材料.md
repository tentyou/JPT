# 监盘通演示材料

## 建议演示时长

8 分钟，另留 2 分钟回答问题。

## 一句话介绍

监盘通把公司 MCP 项目数据、手机现场拍摄和可审计成果打通，让项目人员从“找表、筛表、逐项整理”转为“选项目、批量监盘、直接交付”。

## 演示脚本

### 1. 痛点与方案（1 分钟）

展示传统路径：网页项目列表 → 在线底稿 → 表格筛选 → 手机逐项拍摄 → 人工整理。说明网页结构变化、弱网和重复劳动是主要问题。切换到监盘通首页，介绍 MCP 直连和离线完整快照。

### 2. 安全连接（1 分钟）

进入“线上同步 → 连接设置”，粘贴预先准备的竞赛专用 Token，点击验证。强调新凭据验证成功前不覆盖旧凭据，Token 经 Android Keystore 加密，演示材料中不得出现真实 Token。

### 3. 项目同步（1.5 分钟）

选择测试项目 `20250715002`。展示项目名称、基准日、产权持有单位和报告类型自动填充。启动同步，说明分页完整性校验、单事务更新、弱网失败保留旧清单。

### 4. 统一清单（1.5 分钟）

展示“待盘点、已完成、全部、已排除”筛选。打开一项详细信息，展示所属单位、底稿科目、位置等 MCP 元数据。切换盘点范围，说明修改仅在本地保存。

### 5. 共用照片盘点（2 分钟）

点击“批量选择”，选择同一现场的多项设备，点击“共用照片盘点”。拍摄一至两张照片，页面显示所选资产数量。完成后展示多项资产同时进入已完成状态，并分别查看生成的 PDF。

### 6. 离线与成果（1 分钟）

关闭网络后继续查看清单和照片。展示 Wi-Fi 传输与项目 ZIP 导出。说明当前由客户手动上传，App 不向线上系统写入。

## 建议幻灯片

1. 封面：作品名、团队和参赛单位
2. 业务痛点：传统六步路径
3. 产品流程：MCP → 完整快照 → 现场监盘 → PDF/ZIP
4. 技术架构与安全边界
5. 核心创新：批量共享证据
6. 演示结果：效率、完整性、可追溯性
7. 可复现工程与后续计划

## 演示检查清单

- 使用竞赛专用、可撤销 Token，不在投屏画面展示完整值。
- 提前同步测试项目并准备至少三项同场资产。
- 确认相机、定位和存储权限已授予。
- 准备弱网演示前的本地完整快照。
- 下载 GitHub Release APK 作为备用安装包。
- 现场演示后撤销竞赛 Token。
